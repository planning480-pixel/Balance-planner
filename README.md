# BALANCE Planner

ระบบแผนยุทธศาสตร์และบริหารความเสี่ยง (ERM) กรมสรรพสามิต · แผนยุทธศาสตร์ 2570–2574

- แอปที่ใช้งานจริง: https://claude.ai/artifact/K6GSXE7aFrkKtCrTqNZcJc
- Excise Weekly Insight Update: https://claude.ai/artifact/A6aFeSRLYqU44TJZ1k3X69

## โครงสร้าง

| โฟลเดอร์ | เนื้อหา |
|---|---|
| `src/` | ซอร์สแยกส่วน (CSS/HTML และ JS ตามหน้า) |
| `dist/` | หน้าเว็บที่ build แล้ว (`index.html`) ข้อมูลหน้าสาธารณะ (`public-data.json`) และไฟล์ประกอบ: `news.json` (Hot issue รายสัปดาห์), โลโก้, PDF แผนยุทธศาสตร์ และภาพหน้าแผน |
| `data/` | ข้อมูลตั้งต้น: โครงสร้างแผน (`config_org.json`), ข้อมูลแดชบอร์ดตัวอย่าง (`ops_seed.json`) |
| `insight/` | หน้า Excise Weekly Insight Update และรูปประจำหมวดสินค้า |

## Build

```sh
./build.sh   # รวม src/ → dist/index.html และตรวจ syntax ด้วย node --check
```

## สิทธิ์ผู้ใช้

- **Super admin** (เจ้าของแอป): เห็นและจัดการได้ทุกอย่าง รวมถึงเมนูตั้งค่า (KPI Setting, ตั้งค่าทั่วไป, ข้อมูลแดชบอร์ด, จัดการผู้ใช้)
- **ผู้ใช้ทั่วไป**: เห็นทุกหน้า ยกเว้นแผนงานและรายงานผลของหน่วยงานอื่น และเมนูตั้งค่าทั้งหมด

หมายเหตุ: ตัวเลขในแดชบอร์ดบางส่วนยังเป็นข้อมูลตัวอย่าง (มีป้าย "ข้อมูลตัวอย่าง" กำกับในหน้า)

## หน้าแสดงผลสาธารณะ (Vercel)

เมื่อเปิดนอก claude.ai (เช่นบน Vercel) แอปจะเข้า **โหมดแสดงผล** อัตโนมัติ: ดูได้อย่างเดียว ไม่มีการเข้าสู่ระบบ แสดง Dashboard, KPI Scoreboard, TOP5 Risk, เสายุทธศาสตร์ แผนยุทธศาสตร์ (PDF) และ Excise Insight (`/insight/`) รวมแผนงานที่ไม่ใช่ร่าง (ไม่มีชื่อผู้สร้าง) โดยไม่มีรายงานผลรายเดือน ผู้ช่วย AI ผู้ติดต่อ และเมนูตั้งค่า

อัปเดตข้อมูล: Super admin เข้าแอปบน claude.ai › ตั้งค่าทั่วไป › ข้อมูลแดชบอร์ด › **ส่งออก public-data.json** แล้วอัปโหลดทับไฟล์ `dist/public-data.json` ใน GitHub
